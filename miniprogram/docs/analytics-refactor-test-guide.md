# 7S 分析页重构测试指南

## 一、前置准备

### 1. 安装依赖
在微信开发者工具中：
1. 打开终端，进入 `miniprogram` 目录
2. 执行 `npm install`
3. 点击菜单 **工具 → 构建 npm**

### 2. 部署云函数
右键 `cloudfunctions/getAnalytics` 目录，选择 **上传并部署：云端安装依赖**

## 二、功能测试清单

---

## 三、边界测试

### 1. 无数据状态
- 清空数据库后，应显示"暂无足够的数据生成图表"

### 2. 缓存机制
- 首次加载后，5分钟内再次进入应使用缓存
- 下拉刷新应清除缓存重新加载

### 3. 云函数错误
- 云函数调用失败时，应显示错误提示并尝试使用缓存

---

## 四、已知问题与注意事项

1. **ECharts 组件首次渲染**：首次加载时图表可能需要等待数据返回后才能渲染，属于正常现象。

2. **TypeScript 警告**：`ec-canvas.ts` 中的动态 require 警告可忽略，这是为了兼容微信小程序环境。

3. **缓存版本**：缓存 key 已更新为 `analytics_data_cache_v2`，旧缓存会自动失效。
