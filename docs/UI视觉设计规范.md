# 7S 数字化管理系统 UI 视觉设计规范 (V4.0)

## 一、 设计灵魂 (The Core Spirit)
*   **设计愿景：** 将繁杂的现场管理转化为直观的**“管理艺术”**。
*   **设计原则：** 
    *   **结论导向：** 颜色即状态，数字即重点，文案即建议。
    *   **呼吸感留白：** 宁缺毋滥，用间距和投影代替线条，营造高端 SaaS 质感。
    *   **去绿化方针：** 彻底剔除绿色。使用**珊瑚浅红**代表荣誉，**炭黑色**代表严肃。

---

## 二、 视觉基础规范 (Visual Foundations)

### 1. 色彩系统 (Morandi Palette)
*   **品牌/分析色 (Brand Blue):** `linear-gradient(135deg, #3B82F6, #6366F1)`。用于全站顶部 Header。
*   **荣誉/红榜色 (Honor Red):** `#F87171` (浅珊瑚红)。用于红榜、满分、进步。
*   **严肃/黑榜色 (Strict Black):** `#495057` (深炭灰)。用于黑榜、待改进、警告。
*   **背景底色 (Page BG):** `#F5F7FA` (冷灰色)。让白色卡片具有悬浮感。
*   **文字色:** 主标题 `#1F2937` (深黑)，副标题 `#9CA3AF` (60% 透明度白色/灰色)。

### 2. 字体规范 (Typography)
*   **数字 DNA:** 全站所有数据（分数、名次、百分比）强制统一使用 **DIN Alternate (Bold)**。
*   **文本层级:** 
    *   办公室名称/主标题: 15px - 16px, 加粗。
    *   辅助说明/部门名: 12px, 浅灰色。

### 3. 图标规范 (Iconography)
*   **风格:** 2px 极细线性图标 (Outline Style)。
*   **统一性:** 全站严禁使用实色色块图标或 Emoji，保持线条纤细。

---

## 三、 全页面统一 Header 结构 (The Universal Header)

**核心：彻底解决标题重复与边距不一。**

*   **容器样式:** 16px-20px 圆角渐变卡片。左右留白 24rpx，顶部间距统一设为 **24rpx**。
*   **文案逻辑:** 导航栏写“我在哪”，卡片标题写“我在这里看什么”。
    *   **首页:** 最新表现看板 (实时红黑榜及核心动态摘要)
    *   **评分:** 实地评价终端 (请基于现场实际情况进行客观评分)
    *   **分析:** 全局健康概览 (当前周期的均分汇总与趋势)
    *   **历史:** 数据档案中心 (往期评分记录与结构化档案检索)
*   **交互控件:** 选择器采用 **胶囊形 (Pill)**，背景色为 `rgba(255, 255, 255, 0.15)`，文字为白色。

---

## 四、 页面详细设计准则 (Page-wise Standards)

### 1. 首页：红黑榜荣誉感
*   **名次显示:** 大号 DIN 数字水印，红榜淡红色，黑榜淡灰色。透明度控制在 15%。
*   **分数值:** 红色 (优) / 黑色 (待改进) 的大号 DIN 数字，去掉“分”字。
*   **侧边条:** 4px 宽实色渐变装饰条。

### 2. 打分页：数字化作业质感
*   **图标对齐:** 每一项配以专属的 7S 线性图标。
*   **打分组件:** 使用分段选择器样式，选中态为深蓝色，未选中态为极浅灰。
*   **底部反馈:** 毛玻璃效果状态条，DIN 字体高亮总分，胶囊状进度提示。

### 3. 分析页：数据洞察深度
*   **帕累托图:** 重点高亮（深蓝），非重点弱化（浅灰）。分值内嵌或前置。
*   **建议卡片:** 采用“人话”文案，淡蓝色背景 + 蓝色左侧边条。

### 4. 历史页：结构化档案感
*   **去噪处理:** 去除每一行的装饰性小房子图标。
*   **等级标签:** 采用“优/良/差”浅色底胶囊标签，对齐红/蓝/黑配色。

---

## 五、 UI 优化关键总结 (The Golden Rules)

1.  **投影代替边框:** 全站卡片禁止使用实线边框，统一使用 `box-shadow: 0 10px 30px rgba(0, 0, 0, 0.03)`。
2.  **数字力量:** 每一处数字都是一次视觉反馈，必须用 DIN 字体赋予其权威性。
3.  **色彩即语言:** 不要为了好看而乱涂颜色。红就是荣誉，黑就是异常，蓝就是系统分析。
4.  **文案克制:** 杜绝废话，不重复导航栏。通过副标题的透明度（60%）来拉开视觉层次。

**至此，这套系统在 UI 上已经达到了“企业级管理套件”的标准。它不仅是一个打分工具，更是一个能体现管理层审美与管理深度的数字化橱窗。**
