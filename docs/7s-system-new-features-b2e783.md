# 7S联查评分小程序 - 新功能实施计划

## 概述
为7S联查评分小程序添加三个新功能：部门及办公室管理、并列排名支持、公示榜Excel导出。

## 需求分析

### 1. 部门及办公室管理功能
当前部门数据硬编码在代码中（`DEPARTMENTS_TEMPLATE` 和 `departments.json`），需要改为数据库管理。

**实现方案：**
- 创建 `departments` 云数据库集合
- 创建 `manageDepartments` 云函数，支持增删改查
- 创建 `manageRooms` 云函数，支持办公室的增删改查
- 新增 `pages/admin/departments` 管理页面
- 修改现有页面动态加载部门数据

### 2. 分数相同的部门并列排名
当前 `getLeaderboard` 仅取前3名，没有处理同分并列情况。

**实现方案：**
- 修改 `getLeaderboard` 云函数排名算法
- 红榜：取所有与第3名同分的部门（可能超过3个）
- 黑榜：取所有与倒数第3名同分的部门（可能超过3个）
- 返回时添加 `rank` 字段表示实际排名

### 3. 公示榜Excel导出
根据用户提供的公示文档图片，实现新的Excel格式。

**布局要求：**
- 标题区："职能部室办公环境卫生联查评比结果公示"
- 引言区：包含7S工作推进要求、提高办公环境卫生水平、增强团队凝聚力等描述
- 评比标准区：7条标准（桌面摆放、地面、窗台、文件资料、电器设备、办公椅、整体印象），句末用句号
- 评比结果区：
  - 红榜标题："最优秀的五个部门办公室："（可能超过5个，因并列排名）
  - 红榜内容：序号、部门（办公室 负责人：xxx），同名次并列显示
  - 黑榜标题："待改进的三个部门办公室："（可能超过3个，因并列排名）
  - 黑榜内容：序号、部门（办公室 负责人：xxx），同名次并列显示
- 后续工作区：三条工作要求（使用实际文案）
- 落款："7S联合检查小组" + 日期，右对齐

**格式特点：**
- 白底黑字，无边框线，模拟Word公示文档
- 宋体字体，12号字（标题18号加粗）
- 支持并列排名（同名次部门在同一行，用顿号分隔）
- 显示办公室负责人信息

**实现方案：**
- 在 `exportReport` 云函数中新增第三个工作表"评比结果公示"
- 修改 `generateExcelBuffer` 函数，在同一个Excel文件中生成三个工作表
- 工作表1：评分表（原有）
- 工作表2：红黑榜排名（原有）
- 工作表3：评比结果公示（新增，按图片格式）

## 并列排名规则详细说明

### 红榜排名逻辑（从高到低）
1. 获取所有记录，按分数降序排列
2. 确定第1、2、3名的基准分数
3. 红榜应包含：
   - 第1名及所有与第1名同分的部门
   - 第2名及所有与第2名同分的部门  
   - 第3名及所有与第3名同分的部门
4. 每个部门返回时标注实际排名（rank字段）
5. 公示榜标题使用"最优秀的部门办公室："（具体数量根据并列排名后的实际部门办公室数确定）

**示例：**
- 情况1：A=70, B=70, C=68, D=68, E=66 → 红榜：A(第1名), B(第1名), C(第2名), D(第2名), E(第3名)
- 情况2：A=70, B=68, C=68, D=68, E=66 → 红榜：A(第1名), B(第2名), C(第2名), D(第2名), E(第3名)
- 公示显示：同名次的部门在同一行，用顿号（、）分隔

### 黑榜排名逻辑（从低到高）
1. **重要规则：一个办公室不能同时在红榜和黑榜中，红榜优先**
2. 首先排除已在红榜中出现的所有办公室
3. 从剩余记录中排除满分(70分)的记录
4. 从低分到高分排序
5. 黑榜应包含：
   - 倒数第1名及所有同分的部门
   - 倒数第2名及所有同分的部门
   - 倒数第3名及所有同分的部门
6. 每个部门返回时标注实际排名（从最后开始计数）
7. 公示榜标题使用"待改进的部门办公室："（具体数量根据并列排名后的实际部门办公室数确定）

**示例：**
- 情况1：... F=50, G=50, H=52, I=52, J=52 → 黑榜：F(倒数第1), G(倒数第1), H(倒数第2), I(倒数第2), J(倒数第2)
- 公示显示：同名次的部门在同一行，用顿号（、）分隔

## 公示榜Excel配色要求

**重要：所有单元格使用白底黑字，无边框线，模拟Word公示文档格式**

- 背景色：纯白色（#FFFFFF）

- 标题：加粗处理，居中
- 引言：首行缩进两个字符
- 落款：右对齐
