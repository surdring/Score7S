# 7S 数据分析页面重构计划

基于丰田（TPS）及国内标杆企业的分析模型，将现有"分数堆砌"式分析页重构为"异常发现"与"改进指引"导向的管理仪表盘。

---

## 一、重构目标

将现有三个简单进度条图表升级为**四个**核心分析模块：
1. **全局健康概览** - 决策层 KPI 一览
2. **异常穿透** - 未达标办公室列表（< 60 分）
3. **部门表现分布图** - 九宫格分类定位 → **办公室表现分布图**
5. **动态趋势稳定性** - 带警戒线的时序分析

---

## 二、技术方案

### 2.1 图表组件选型

微信小程序原生不支持复杂图表，需引入 **ECharts 微信小程序版**：
- 仓库：`ecomfe/echarts-for-weixin`
- 优势：支持雷达图、散点图、折线图、柱状图
- 体积：约 300KB（按需定制可更小）

### 2.2 得分率标准化

将所有分数转换为得分率百分比展示：
```
得分率 = (当前分数 / 该项满分) × 100%
```

色彩联动规则：
- ≥95%：绿色（优秀）
- 80%-95%：蓝色（良好）
- 60%-80%：黄色（及格）
- <60%：红色（不及格）

## 八、变更记录

### 2024-03-29 重大变更

1. **删除 7S 均衡性雷达图**
   - 删除原因：用户体验不佳，信息价值有限
   - 删除范围：UI（WXML/WXSS）、逻辑（TS）、云函数数据计算

2. **达标线调整**
   - 原标准：80 分达标
   - 新标准：60 分达标
   - 影响范围：达标率计算、异常穿透筛选、象限分析分界线

3. **UI 优化**
   - 四象限散点图：添加极淡背景色分区、坐标轴单位、标签防碰撞
   - 趋势图：数据稀疏时改用面积折线图、警戒线视觉降噪（opacity 0.25）
   - 帕累托图：移除双轴、Top3 深橙色/其余浅灰、圆点直接标注百分比
   - 整体页面背景：调整为 `#F8F9FA` 增强卡片层次感

4. **口径调整（2024-03-29）**
   - 散点图口径：部门 → 办公室（按部门+房间聚合）
   - 数据粒度：从17个部门扩展到35个具体办公室
   - 象限分类、重点关注名单均改为办公室维度
