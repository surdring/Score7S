# 7S 联查评分小程序 - 数据分析方案

基于 7S 管理（整理、整顿、清扫、清洁、素养、安全、节约）的全球最佳实践，结合丰田（TPS）及国内标杆企业的分析模型，数据分析不应只是"分数的堆砌"，而应是**"异常的发现"**与**"改进的指引"**。

---

## 一、核心分析逻辑：从"分数"转向"三个维度"

1. **改善稳定性（Trend Analysis）**：是"突击式扫除"还是"持续性维持"？
2. **异常聚焦（Pareto/Heatmap）**：20% 的部门/项目贡献了 80% 的扣分吗？
3. **部门表现分布（Scatter Plot）**：谁在"危险区"，谁是"标杆"？

---

## 二、页面重构原型方案

### 1. 顶部：全局健康概览（决策层最关心的 KPI）
*   **综合平均分**：本周期全公司均分。
*   **达标率**：得分 ≥60分的办公室占比。
*   **环比涨跌幅**：与上一周期相比，管理水平是在进步还是退步（↑ 5.2%）。

### 2. 异常穿透：未达标办公室列表
*   **设计**：默认显示汇总卡片`"本周有 X 个办公室未达标"`。点击展开二级列表。
*   **标准**：总分 < 60 分视为未达标。

### 3. 帕累托分析：扣分项 Top 3（核心：聚焦重点）
*   **逻辑**：按**扣分总额**排。
*   **展示**：横向条形图 + 累计占比折线。
*   **色彩**：Top 3 使用深橙色（#EA580C），其余使用浅灰色（#D1D5DB）。
*   **文案**：例如："本月全公司 **66%** 的分数流失在 **桌面摆放、电器设备、文件资料** 三项"。
*   **管理动作**：这就指引了下周的专项治理方向。

### 4. 办公室表现分布图（针对 17个部门、35个办公室的扩展性）
*   **设计：九宫格散点图**（横轴：检查频次；纵轴：平均分数）。
*   **口径**：按**办公室**（部门+房间）聚合，如"供应一部 101"。
*   **视觉优化**：
    *   四象限背景填充极淡底色（标杆区淡绿、运气区淡蓝、危险区淡红、观望区淡黄）
    *   坐标轴标注单位："检查频次（次）"、"平均分数（分）"
    *   标签防碰撞：增加白色半透明背景和 Y 轴偏移
*   **分类处理**：
    *   **标杆区（高频高分）**：检查多、分数高 → 重点奖励
    *   **运气区（低频高分）**：检查少、分数高 → 需增加检查频次确认真实性
    *   **危险区（高频低分）**：检查多、分数低 → 重点整改、驻场指导
    *   **观望区（低频低分）**：检查少、分数低 → 管理死角，需关注
*   **达标线**：60 分（横向分界线）

### 5. 动态趋势：稳定性分析
*   **图表**：面积折线图（带渐变填充），填补数据稀疏时的留白。
*   **警戒线**：60 分达标线（极淡红色虚线，opacity 0.25，无标签）。
*   **标注**：数据点上方直接显示数值。

## 三、达标标准（已确定）

| 分数区间 | 状态 | 说明 |
|---------|------|------|
| **≥ 60 分** | **达标** | 合格，计入达标率统计 |
| **< 60 分** | **未达标** | 不合格，列入异常穿透列表 |

**历史调整**：达标线从 80 分调整为 60 分，简化评定标准。

---

## 四、技术实现要点

### 得分率标准化
将所有分数转换为得分率百分比展示：
```
得分率 = (当前分数 / 该项满分) × 100%
```

色彩联动规则：
- ≥95%：绿色（优秀）
- 80%-95%：蓝色（良好）
- 60%-80%：黄色（及格）
- < 60%：红色（不及格）

### 页面底色
- 页面背景：`#F8F9FA`（极浅灰）
- 卡片背景：`#FFFFFF`（纯白）
- 视觉层次：卡片"浮"于背景之上

## 六、总结

优化后的分析页是一个**"7S 管理仪表盘"**。它告诉管理者：
- **现状如何**（KPI 概览）
- **谁最需要帮扶**（异常穿透 + 危险区分布）
- **下周抓什么**（扣分 Top 3）
- **趋势如何**（动态趋势稳定性）
